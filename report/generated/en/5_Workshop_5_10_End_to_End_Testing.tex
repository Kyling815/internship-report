\vspace{0.5em}\noindent\textbf{Objective}\par

Define an acceptance test set for the deployed Internship Application
Tracker and record which results are verified, implemented but still
requiring runtime evidence, proposed, or not completed.

\vspace{0.5em}\noindent\textbf{Architecture context}\par

End-to-end tests must cover the full public path:

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{Browser {-}\textgreater{} CloudFront {-}\textgreater{} S3 or ALB {-}\textgreater{} EKS workloads {-}\textgreater{} managed AWS services}
\end{Highlighting}
\end{Shaded}

They must also cover asynchronous paths:

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{Backend {-}\textgreater{} PostgreSQL outbox {-}\textgreater{} dispatcher {-}\textgreater{} SQS {-}\textgreater{} Lambda {-}\textgreater{} DynamoDB dedupe {-}\textgreater{} S3 archive {-}\textgreater{} SES}
\end{Highlighting}
\end{Shaded}

checks pass, EKS workloads are Ready,

Lambda smoke-test path has exported proof for event processing, archive,
and email result.

\vspace{0.5em}\noindent\textbf{Outcome}\par

The E2E test plan is evidence-aware. It avoids marking tests passed
solely because code exists and records which runtime checks still
require exported evidence.
