\vspace{0.5em}\noindent\textbf{Objective}\par

Build the React/Vite frontend, publish it to a private S3 bucket, and
serve it through CloudFront.

\vspace{0.5em}\noindent\textbf{Architecture context}\par

The frontend is currently deployed as static files, not as an EKS
workload. The old frontend Kubernetes Deployment, Service, HPA, PDB, and
frontend ALB Ingress were removed so future EKS app deployments cannot
recreate them.

The \texttt{deploy-\allowbreak{}frontend} job:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Configures AWS credentials through OIDC.
\item
  Sets Node.js from workflow \texttt{NODE\_\allowbreak{}VERSION}.
\item
  Verifies ALB health at \texttt{/\allowbreak{}api/\allowbreak{}health/\allowbreak{}ready} and
  \texttt{/\allowbreak{}chat/\allowbreak{}health/\allowbreak{}ready}.
\item
  Runs \texttt{scripts/\allowbreak{}ci/\allowbreak{}deploy-\allowbreak{}frontend.\allowbreak{}sh}.
\item
  Uploads frontend files to S3.
\item
  Creates a CloudFront invalidation.
\end{enumerate}

\vspace{0.5em}\noindent\textbf{Removal of old Kubernetes frontend
resources}\par

The current architecture intentionally removes frontend Kubernetes
resources. Do not recreate:

\begin{itemize}
\tightlist
\item
  \texttt{Deployment/\allowbreak{}frontend}
\item
  \texttt{Service/\allowbreak{}frontend}
\item
  frontend HPA
\item
  frontend PDB
\item
  frontend-specific ALB Ingress
\item
  \texttt{FRONTEND\_\allowbreak{}IMAGE} deployment path for EKS app deploy
\end{itemize}

The frontend is built once and served as static files from S3 and
CloudFront.

\vspace{0.5em}\noindent\textbf{Outcome}\par

Frontend deployment is complete when the Vite build is in S3, CloudFront
has invalidated cached objects, public users can load the application
through \texttt{https:/\allowbreak{}/\allowbreak{}dhm2rz5nmsibj.\allowbreak{}cloudfront.\allowbreak{}net}, and dynamic
routes reach backend/chat through CloudFront and the ALB.
