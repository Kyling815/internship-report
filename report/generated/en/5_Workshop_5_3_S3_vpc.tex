\vspace{0.5em}\noindent\textbf{Using Gateway endpoint}\par

In this section, you will create \textbf{a Gateway eendpoint} to access
\textbf{Amazon S3} from \textbf{an EC2 instance}. \textbf{The Gateway
endpoint} will allow upload an object to S3 buckets without using
\textbf{the Public Internet}. To create an endpoint, you must specify
the VPC in which you want to create the endpoint, and the service (in
this case, S3) to which you want to establish the connection.
