\vspace{0.5em}\noindent\textbf{Prerequisites}\par

\vspace{0.5em}\noindent\textbf{Objective}\par

Prepare the accounts, permissions, tools, repository access, quotas, and
environment variables required to deploy and verify the Internship
Application Tracker.

\vspace{0.5em}\noindent\textbf{Architecture context}\par

This project uses GitHub Actions and AWS OIDC for production deployment.
Local tools are still needed for inspection, emergency verification, and
manual recovery. Do not use long-lived AWS access keys in the CI/CD
pipeline.

\vspace{0.5em}\noindent\textbf{Expected result}\par

\begin{itemize}
\tightlist
\item
  The AWS account ID is the project account ID and should be redacted
  from published screenshots or logs.
\item
  The active region is \texttt{ap-\allowbreak{}southeast-\allowbreak{}1}.
\item
  \texttt{kubectl} can inspect the \texttt{internship} namespace.
\item
  GitHub Actions can assume the deploy role through OIDC.
\item
  Required secrets are stored in GitHub environment secrets, not in
  source control.
\end{itemize}
