\vspace{0.5em}\noindent\textbf{Objective}\par

Deploy and verify the data layer used by the Internship Application
Tracker: RDS PostgreSQL, ElastiCache Redis, DynamoDB chat tables, and
DynamoDB Lambda idempotency table.

\vspace{0.5em}\noindent\textbf{ElastiCache Redis}\par

The production Redis replication group is
\texttt{internship-\allowbreak{}prod-\allowbreak{}redis}, and I verified it as \texttt{available}

events can be broadcast between multiple chat pods.

\end{Shaded}

The chat service reads \texttt{REDIS\_\allowbreak{}URL} from
\texttt{internship-\allowbreak{}secrets}. In production, Redis must be reachable from
chat pods and should not be exposed publicly.
