\vspace{0.5em}\noindent\textbf{Hạ tầng AWS}\par

\vspace{0.5em}\noindent\textbf{Mục tiêu}\par

Tài liệu hóa chi tiết toàn bộ hạ tầng AWS phục vụ cho công tác triển
khai production thực tế và cung cấp đầy đủ các chuỗi lệnh kiểm chứng an
toàn ứng với từng cụm tài nguyên cốt lõi trong hệ thống.

\vspace{0.5em}\noindent\textbf{Phạm vi}\par

Chương tài liệu này tập trung ghi nhận trọn vẹn những tài nguyên đã thực
thụ triển khai có kèm thư viện bằng chứng bảo an, điểm tên thẳng thắn
những thông số trường mục còn ngụ đợi lệnh chiết xuất rà tra cẩu bằng
AWS CLI, và ra riêng danh mục đề xuất gia cố an ninh tự nguyện cho nhà
phát triển bám đuổi về sau.

\vspace{0.5em}\noindent\textbf{Bối cảnh kiến
trúc}\par

Hạ tầng nền tảng tự do bấu víu cho một kiến trúc kết hợp vi diệu giữa
hai chiến tuyến Cloud CDN ngoại vi và cỗ máy container tập trung:

\begin{itemize}
\tightlist
\item
  Cầu nối CloudFront và kho S3 chuyên trách phân phối trang giao diện
  frontend.
\item
  Cánh cổng ALB luân chuyển gạn chia tải truy nhập động lao thẳng vào
  bên trong EKS.
\item
  Cụm máy chủ EKS vững chí gìn bám, cưu mang toàn cõi cho chuỗi workload
  phần mềm ngụ trực trăn dài hạn.
\item
  Cơ quan cơ sở dữ liệu được quản lý (managed databases), kênh truyền
  tin, kho object storage, dịch vụ Lambda, máy gửi mail SES cùng cỗ cống
  suy luận SageMaker chễm trệ dựng cao tường mang lại dịch vụ nền tảng
  tráng kiệt cho hệ thống.
\item
  Dây chuyền tự động trên GitHub Actions ung dung múa trượt triển khai
  qua ranh giới OIDC mà vội buông rơi hoàn toàn việc cầu cạnh các khóa
  AWS access keys vô hạn ngày lì lợm.
\end{itemize}

\vspace{0.5em}\noindent\textbf{Nền tảng mạng}\par

Cụm máy EKS trong bối cảnh sản xuất production nhất định khẩn khỏm đòi
hỏi cấu trúc mạng VPC có chia đôi phân cách giữa các subnet public và
private:

\begin{itemize}
\tightlist
\item
  Các subnet public thọ nuôi cụm máy cân bằng tải hứng lưu lượng từ thế
  giới public bên ngoài và kho vây các máy NAT Gateway.
\item
  Các subnet private bao vây an ninh êm bế nuôi dưỡng cụm máy cọc worker
  nodes của EKS cùng đường rẽ vào bên trong của mạng dịch vụ AWS được
  quản lý.
\item
  Một cống Internet Gateway có chức năng khai quan cho lưu lượng public
  trượt thiền vào và mở đàng cho lưu lượng từ NAT ung dung phi xuất
  ngoại.
\item
  Một trạm chuyển giao NAT Gateway ra mặt bao sắm cho dàn máy nằm an
  tịnh trong lòng subet private đặc quyền tiếp cận ra vạch ngoài
  Internet để bồi nạp lấy container image, trao đổi chuỗi gọi tới AWS
  APIs, tải về tệp gói phụ trợ, đồng thời giao đãi mạch nảy theo cụm
  điều phối control-plane.
\end{itemize}

Cần bằng chứng:

\begin{itemize}
\tightlist
\item
  Thông số định danh VPC ID, tuy rằng biến cố lỗi xử lý trong sự cố khắc
  phục đã kiên thấu xác tín số \texttt{vpc-\allowbreak{}0cfee519122ae18b4} từng bị sử
  dụng để cầu khấn rước AWS Load Balancer Controller múa việc.
\item
  Các mã số nhận diện Public subnet IDs.
\item
  Các mã số nhận diện Private subnet IDs.
\item
  Danh bạ số liệu bảng định tuyến Route table IDs.
\item
  Nhóm bảo mật Security group IDs và điều luật tường lửa vây kèm.
\item
  Số hiệu của NAT Gateway ID kết hợp mã cấp tài khoản địa chỉ Elastic IP
  allocation ID.
\end{itemize}

\item
  các dải phân tuyến (paths): \texttt{/\allowbreak{}api}, \texttt{/\allowbreak{}chat},

thiêu web frontend, gắn thấu quan trắc, thí trù nghiệm thu cùng tháo gỡ
quy thu chi cước tài nguyên bám sát kế tiếp ngay sau đây.
