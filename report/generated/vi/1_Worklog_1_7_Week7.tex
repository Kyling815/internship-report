\vspace{0.5em}\noindent\textbf{Triển khai kỹ
thuật}\par

The target production environment is centered on EKS namespace
\texttt{internship}. Backend and chat are long-running Kubernetes
Deployments. PostgreSQL, Redis, DynamoDB, SQS, S3, CloudFront, and
SageMaker are managed AWS services outside the cluster.

\textbf{Mô tả sơ bộ.} CloudFront chuyển lưu lượng ứng dụng qua ALB công
khai đến backend và chat service. Backend dùng RDS, S3 và hàng đợi
outbox SQS; chat dùng ElastiCache và DynamoDB; processing worker gọi AI
service và SageMaker, còn dispatcher gửi sự kiện vào SQS.

Runtime variables such as \texttt{DATABASE\_\allowbreak{}URL}, \texttt{REDIS\_\allowbreak{}URL},
\texttt{OUTBOX\_\allowbreak{}QUEUE\_\allowbreak{}URL}, and \texttt{AWS\_\allowbreak{}REGION} are treated as
deployment inputs or Kubernetes secret/config values. The report does
not include their secret values.

\vspace{0.5em}\noindent\textbf{Bài học rút ra}\par

Production Kubernetes deployment depends on more than manifests. IAM,
controller readiness, target group convergence, network routing, health
endpoints, and secret handling must all be validated separately.
